Concordo / Não concordo

Como está o tempo hoje?
Hoje o tempo está bom. / ótimo! — Today the weather is good. / great!
Hoje o tempo está mau. / péssimo! — Today the weather is bad. / awful!

Concordo! Para mim, também. — I agree! For me too.
Não concordo. Para mim, está… — I disagree. For me, it's…

Para ti, qual é o melhor dia da semana?

Para mim, é a sexta, porque… — For me, it's Friday, because…
Mon–Fri take feminine article a. Sábado and domingo take masculine o.

Palavra do Dia — Calão
Calão
o briol
freezing cold weather (slang)
Used informally to describe bitter cold. Amanhã vai estar um grande briol! — Tomorrow it's going to be absolutely freezing!
Diz-se Assim!
Expressão
Sábado vai estar muito abafado.
Saturday is going to be very muggy.
Abafado = hot, humid, and stifling — the Lisbon August feeling. Distinct from just calor. You'll hear it constantly in summer weather forecasts.

Futuro Próximo — ir + infinitivo
Estrutura

ir (present tense) + infinitive = near future. Equivalent to English "going to."
Vou jantar fora. — I'm going to eat out.

SujeitoirExemplo
eu vou Vou jantar fora.
tu vais Vais sair com os teus amigos?
você / ele / ela vai Vai fazer o trabalho de casa.
nós vamos Vamos organizar uma viagem aos Açores.
vocês / eles / elas vão Vão ficar aqui até às 18h.

Exemplos em Contexto
PortuguêsEnglish

Tempo + Futuro Próximo

E amanhã, como vai estar o tempo em Lisboa?
Amanhã vai estar sol / vento / chuva / nublado / trovoada / nevoeiro.
— Tomorrow it's going to be sunny / windy / rainy / cloudy / stormy / foggy.
