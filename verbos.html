Verbos Irregulares — Presente (eu / você)
Nota
These are the verbs that don't follow predictable patterns. Highlighted in red = irregular form. Memorise as chunks — don't try to derive them from rules.
Verbos Regulares -AR — Paradigma
falar
to speak — model for all -AR verbs
eufalo
tufalas
você/ele/elafala
nósfalamos
vocês/elesfalam
O Padrão
Remove -ar → add ending: -o / -as / -a / -amos / -am. The eu form always ends in -o. The você form always ends in -a. These two are your priority.

decidir
to decide — model for -IR verbs
eudecido
tudecides
você/ele/eladecide
nósdecidimos
vocês/elesdecidem
O Padrão
-ER: remove -er → add -o / -es / -e / -emos / -em.
-IR: remove -ir → add -o / -es / -e / -imos / -em.
Key difference: nós form — vivemos vs decidimos.
